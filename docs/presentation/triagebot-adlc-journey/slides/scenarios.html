Scenarios

Nine paths a run can take, all handled by the same state machine

ScenarioWhere it happenedRun statesResult

EscalationT5building → escalatedA person completes the run
Exception with waiverT5escalated → sign-off → closedOwner, expiry and safeguard recorded
Rework limit reachedSecond use case, T1fourth rejection → escalatedA person takes over the run
Prerequisite missingAny terminalopened → blockedWaits until the evidence exists
Event from operationsT8 → T9review pass, then a drift eventRe-entry decided by change class
The first seven paths ran in the rehearsed demo; the rework-limit case is the demo’s second use case, whose T1 is rejected four times. Prerequisite blocking is covered by the platform’s tests rather than the demo. Engineers: a delivery that keeps failing goes to the dead-letter queue, which only the CoE role can see and replay.
