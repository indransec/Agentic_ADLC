Ballpark in USD per month at pay-as-you-go list prices; medium traffic: ~20 use cases, ~300 runs and ~50 users a month. Verify in the Azure Pricing Calculator.

Assumptions: about 20 use cases in the lifecycle with 8 live, 300 terminal runs a month, 50 named users, about 150k input and 30k output tokens per run on a Sonnet-class model, 60 to 100 GB of telemetry, 1 TB of evidence after a year, private endpoints everywhere and a zone-redundant database. Standalone midpoints: compute about $925 (platform apps and pilot environments), data about $700 (PostgreSQL HA, Blob, AI Search), edge, gateway and messaging about $1,750 (Front Door Premium, API Management Standard v2, Service Bus Premium), security and operations about $900 (Monitor, Defender, network, registry, DevOps, Key Vault), tokens about $1,000. Lean uses Front Door Standard, Service Bus Standard, API Management Basic v2 and AI Search Basic. On existing services, the platform pays only for its dedicated compute, database, storage, search and private endpoints, plus metered log ingestion and Defender; tokens are near zero if provisioned throughput has headroom. Reservations or a savings plan take 30 to 50 percent off database and compute. A live agent’s own tokens belong to its use case: TriageBot at about 1,000 incidents a day is roughly $500 to $800 a month on a Sonnet-class model.
