Lap 1

A rework can cross terminals. The root causes are a catalogue, and each one maps to the terminal that owns the fix: an implementation defect goes to build, a requirement gap to T1. In the journey chart this shows as an arrow backwards. The dashboard groups reworks by root cause so the portfolio can see which stage leaks most.
