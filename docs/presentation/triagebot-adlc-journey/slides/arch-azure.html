A reference mapping to typical enterprise Azure standards; confirm each choice with your cloud platform team. Hosting: Container Apps for web, API, workers and MCP servers (AKS if mandated); same images as the MVP. Events: the PostgreSQL outbox stays the source of truth; a relay publishes committed events to Service Bus Premium; the event router consumes with sessions keyed by use case so order holds; agent-step workers scale on queue length with KEDA, capped by model quota; timers and monitors run as one worker or a scheduled job. Data: PostgreSQL Flexible Server, zone-redundant, dedicated because it holds the ledger; evidence files in Blob Storage with versioning and WORM retention; optional digests to Azure Confidential Ledger. Models: API Management AI gateway in front of Microsoft Foundry, Claude first, Azure OpenAI as fallback, token limits per subscription. Identity: Entra ID OIDC for people, app roles mapped to roles.yaml, Microsoft Graph for the directory check, managed identities for services, Key Vault for the session secret and tool token key. Guardrails: AI Content Safety Prompt Shields; Foundry AI red teaming at T5. Source and CI: Azure DevOps Repos and Pipelines, deploy by image digest from ACR; Azure Boards for Phase 2. Pilot rollout: Container Apps revisions with traffic weights for canary; shadow needs request mirroring in API Management. Verify before presenting: Claude availability in Foundry for your region, MCP support in API Management, Entra Agent ID maturity for the agent registry.
