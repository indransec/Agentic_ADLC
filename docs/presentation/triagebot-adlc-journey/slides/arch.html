Technology-agnostic view of the solution architecture (SA §4). People act only through the experience layer, the web app or the work tracker board. Agents act only through orchestration and policy, and reach models and tools only through gateways. Everything is recorded in the data and evidence layer. The pilot environments, where the agents being built run, sit outside the platform and are reached through a single bridge. The numbered path is one run, as in the journey slides. Each layer sits behind an interface (run state machine, evaluate and authorize, router, model gateway, MCP registry, identity provider), which is why the next slide can map it to Azure without changing the design.
