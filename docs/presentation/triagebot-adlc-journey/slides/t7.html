Lap 1

TriageBot is low tier, so the canary-breach control (CTL-T7-04) does not gate it; the rehearsed run still steps through shadow, canary and full, and every reading is checked against observability. The platform files each reading under the traffic mode set last before it; a breach rolls back automatically and opens a rework routed by root cause. The agent registry is the enterprise catalogue of live agents (an MCP server, mocked in the MVP): T7 writes name, version, package hash, owner, status, autonomy level and dependants, and CTL-T7-09 checks the entry is really in the registry. From here the agent is in production and counts as live on the portfolio dashboard. In the MVP the deployment pipeline is simulated, and the registry and CMDB are mocks with the same tool scopes as the real systems.
